> 目标：在一台 Windows 机器上独立跑通本项目全流程测试。2026-09-09 在负责人本机实测验证。
> 术语查《项目术语通俗手册》；协作流程见《协作开发指南》§2。

## 1. 环境组成（已配好）

| 组件 | 状态 | 说明 |
|---|---|---|
| Python 虚拟环境 `.venv/` | ✅ Python 3.12 | 已装：requests / pymodbus 3.8.x（服务端 API 需 <3.9）/ pytest / jsonschema / mujoco 3.12 / numpy |
| OpenPLC 运行时 | ✅ Docker 容器 `openplc` | `docker run -d --name openplc -p 8080:8080 -p 502:502 fdamador/openplc`（Web :8080，Modbus :502） |
| matiec 工具链（链路 A） | ✅ 提取于 `workspace/matiec_toolchain/` | 来自 openplc 容器，L3 用法见 lx 文档 §6.1 Docker recipe |

**全部命令用 `.venv` 的 Python**：`.venv\Scripts\python.exe …`（PowerShell）或 `.venv/Scripts/python.exe …`（Git Bash）。

## 2. 分层测试命令（由便宜到贵）

```bash
cd "D:\Study\SIMENS PLC"

# L2 单元测试（无需任何运行时，秒级）
.venv/Scripts/python.exe -m pytest tests/ -q            # 主套件 190 项（xml2st/一致性/编排器/AML）
.venv/Scripts/python.exe -m pytest toolchain/tests/ -q  # 链路 A L2 6 项
.venv/Scripts/python.exe -m pytest runtime/tests/ -q    # MuJoCo Modbus 桥 9 项

# L1 静态校验（秒级，契约②）
.venv/Scripts/python.exe src/pipeline/xml2st.py src/plc/motion3axis.xml --check

# L3 在线验收（需 openplc 容器在跑）
.venv/Scripts/python.exe src/pipeline/run_deploy.py --xml src/plc/motion3axis.xml   # 部署+真编译
.venv/Scripts/python.exe src/pipeline/scenario_motion3axis.py                       # 47 项行为验收

# 一键回归（L1→L2→L3 全场景，~2.5 分钟）
.venv/Scripts/python.exe src/pipeline/run_regression.py
#   结果 JSON：workspace/regression_result.json；运行时不可达自动 SKIP，--require-online 强制
```

## 3. 部署服务方式（agent 闭环对接）

```bash
.venv/Scripts/python.exe src/pipeline/serve.py &      # HTTP :8600
curl -X POST http://127.0.0.1:8600/deploy --data-binary @src/plc/motion3axis.xml
curl http://127.0.0.1:8600/status                     # 运行时状态 + prog_id + 场景名
```
