> **维护规则**（纳入主方案 §8 工程治理）：
> 1. 每人只维护**自己的区块**，每次工作会话结束、代码合入前更新；
> 2. 需要他人配合时，写在"待配合"小节并 @ 对方区块；对方响应后在原条目标 ✅ 并注明日期；
> 3. 共同议题区需三方达成一致后才可标记"已决议"；
> 4. 底部变更记录每次更新留痕（一行）。
>
> 分工代号：**lx = PLC 执行侧**、**csk = 仿真验证侧**、**gc = 智能体与闭环侧**（详见主方案 §8.1）。模块编号体系（2026-09-02 架构 v1.1 起）：**① 需求理解 / ②a PLC 代码生成 / ②b 仿真环境生成 / ③a PLC 执行引擎 / ③b Isaac Sim 仿真引擎 / ④ 验证与反馈**，详见主方案 §1.3。
