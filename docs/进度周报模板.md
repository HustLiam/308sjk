# 本周总体进度

## 总体目标

工厂的人把工艺需求说出来（比如"三个轴按这个轨迹走，画个圆"），再给一份设备描述文件。AI 理解需求后，自动生成标准格式的 PLC 程序（PLCopen XML），自动部署到一个软 PLC 上跑起来，再接到仿真环境里让设备"真动起来"，仿真结果自动判定合格不合格——不合格就把错误信息喂回给 AI 重写，直到验收通过。全程不用人碰，最后人拿到的是一份验证过的、能直接下到真实 PLC 的程序。

# 智能体侧

# PLC仿真侧
由于轴对象、工艺对象、以及类似倍福那种mc运动库中的各种模块、底层连接EtherCAT这些概念都是不完全属于iec61131-3的，而61131-10是基于61131-3的交换形式，直接使用倍福、西门子plc的编程库、模块，在开源PLC Runtime中无法运行，需要要自定义一套基于61131-3的简单规则，只使用61131-3代码子集来作为智能体程序生成和仿真的基础。
目前我们先抽象自定义一套轴对象结构，然后基于PLC Open Motion Control的标准来自定义一套运动控制模块，以便上层智能体生成代码直接调用。
## 轴对象（Axis Object）概念
```
一个"轴对象" = 插补引擎实例 + 轴参数 + IO 绑定
                │              │          │
                │              │          └─ 位置指令输出 / 编码器反馈输入的 %QW 地址
                │              └─ 行程范围、最大速度、加速度、到位窗口
                └─ INTERP FB 实例（梯形轨迹规划，每扫描输出一个插补点）
```
在生成方案中，轴对象是一个声明式定义，agent 只需提供参数，模板自动展开为 ST 代码：
```
{
  "axes": [
    { "name": "x", "travel": [0, 800], "unit": "mm",
      "vmax": 200, "accel": 500, "poswin": 2,
      "io": { "cmd": "%QW10", "fb": "%QW0" } },
    { "name": "z", "travel": [0, 300], "unit": "mm",
      "vmax": 100, "accel": 300, "poswin": 1,
      "io": { "cmd": "%QW11", "fb": "%QW1" } }
  ]
}
```
## PLCopen Motion Control 对齐
MC 块命名与语义对齐 PLCopen MC Part 1 单轴子集，作为应用层的固定 API
| MC 块 | 输入（要点） | 输出 |
|---|---|---|
| `MC_Power` | Enable, EnablePositive/Negative（CiA402 不分方向，仅门控） | Status, Busy, Error |
| `MC_Reset` | fire | Done, Busy, Error |
| `MC_Stop` | fire（电平）, v_act | Done, Busy, Error |
| `MC_Halt` | fire, ax_busy | Stopping, Done, Busy, Error（受控减速停不失能） |
| `MC_MoveAbsolute` | fire, Position, Velocity/Acceleration/Deceleration, sw, abort_bus | Done, Busy, Active, CommandAborted, Error, ErrorID |
| `MC_MoveRelative` | fire, Distance, ActualPosition, 动力学, sw, abort_bus | 同上（绝对目标 = 触发时实际位置 + Distance） |
| `MC_MoveJog` | JogForward/Backward, Velocity, cur_pos, sw | Busy, Error（起跳锚定实际位置） |
| `MC_Home` | fire, sw | Done, Busy, Error |
| `MC_ReadStatus` | Enable, sw, interp_busy, v_act | Valid, Moving, StandStill, Disabled, ErrorStop |
| `MC_ReadActualPosition` | Enable, ActualPosition | Valid, Position |
