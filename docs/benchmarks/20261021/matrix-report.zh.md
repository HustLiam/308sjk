## 口径与范围

- 完整任务重新调用模型生成需求、测试计划和完整XML。人工未逐项修改控制程序，无种子程序替代。
- 总成功要求流程final且独立请求检查通过。未触发条件的逻辑空集通过不算行为已验证；编译失败时在线检查未执行。
- 模型调用按独立timing记录计数；一次逻辑调用内的传输回退归入同一条计时，不用于推算HTTP请求数或费用。
- X/Y为0..100工程坐标，Z为毫米。正多边形和圆尺度为半径，椭圆半轴为scale与scale/2，长方形宽高为2*scale与scale，非规则图形顶点见原protocol.json。
- 覆盖正三/四/五/六/七边形、圆、长方形、非正凸五边形、凹六边形、椭圆，各两个尺寸；曲线采用36段近似。
- 最终路点须在末样本保持；派生状态响应预算仅40ms并从反馈源变化计时；位置、路径和安全要求保持原定义。
- tests本地426项通过，1项Windows原生编译测试缺工具链排除。其他设备只有离线通用条件回归，不声称跨设备物理测试完成。
- 每个尺寸仅有一个完成任务结果，另有一次完整留档的中断尝试。本集合成功率不等于任意设备和任意任务的可靠性。
- cases.csv含逐任务结果；iterations.csv含每轮耗时、通过数、原始失败证据和版本选择理由。各批次provenance_audit.json与frozen_source_audit.json保存模型来源和版本审计。
