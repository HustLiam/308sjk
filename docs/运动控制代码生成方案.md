# 运动控制代码生成方案（轴对象模板）

> **适用范围**：仅运动控制场景。非运动场景（分拣/液位/交通灯等）不走此方案，保持原有生成模式。
> **链路归属**：链路 A（Isaac 进程内）+ 链路 B-real（IgH EtherCAT + 真实驱动器）。
> 链路 B-sim（OpenPLC + Modbus）仅用于软件级 CI 门禁。

---

## 1. 轴对象（Axis Object）概念

```
一个"轴对象" = 插补引擎实例 + 轴参数 + IO 绑定
                │              │          │
                │              │          └─ 位置指令输出 / 编码器反馈输入的 %QW 地址
                │              └─ 行程范围、最大速度、加速度、到位窗口
                └─ INTERP FB 实例（梯形轨迹规划，每扫描输出一个插补点）
```

在生成方案中，轴对象是一个**声明式定义**，agent 只需提供参数，模板自动展开为 ST 代码：

```json
{
  "axes": [
    { "name": "x", "travel": [0, 800], "unit": "mm",
      "vmax": 200, "accel": 500, "poswin": 2,
      "io": { "cmd": "%QW10", "fb": "%QW0" } },
    { "name": "z", "travel": [0, 300], "unit": "mm",
      "vmax": 100, "accel": 300, "poswin": 1,
      "io": { "cmd": "%QW11", "fb": "%QW1" } }
  ]
}
```

## 2. 生成模板结构

生成的 PLCopen XML 固定包含以下 POU：

| POU | 来源 | 说明 |
|---|---|---|
| `INTERP` | **标准库**（一份拷贝，不随场景变化） | 插补引擎：梯形规划，每扫描输出一个位置设定点；按命令动力学（vel/acc/dec）执行，支持受控中止 |
| `DRIVE402` | **标准库** | 驱动器模型：CiA 402 状态机 + 位置环（CSP 跟随） |
| `MC_*`（10 块） | **标准库**（PLCopen MC 对齐层，2026-09-09） | 应用指令 API：Power/Reset/Stop/Halt/MoveAbsolute/MoveRelative/MoveJog/Home/ReadStatus/ReadActualPosition |
| `PLC_PRG` | **按场景生成** | 应用逻辑 + 轴实例化 + IO 接线 |

### 2.1 INTERP（标准库，所有场景共用）

```st
FUNCTION_BLOCK INTERP
  VAR_INPUT
    fire : BOOL;          (* 启动新插补（上升沿） *)
    pos_target : INT;     (* 目标位置 *)
    hold_req : BOOL;      (* 受控暂停（MC_Halt：减速保持） *)
    vel_req : REAL;       (* 命令速度（MC 块动力学参数锁存到总线） *)
    acc_req : REAL;       (* 命令加速度 *)
    dec_req : REAL;       (* 命令减速度 *)
  END_VAR
  VAR_OUTPUT
    Setpoint : INT;       (* 插补点（周期位置设定值 → 驱动器） *)
    Busy : BOOL;
    Done : BOOL;
    Aborted : BOOL;       (* hold 减速到零速即中止（供 MC 层置 CommandAborted） *)
  END_VAR
  VAR
    edge_ir : BOOL;       (* 边沿检测 *)
    pos, vel, tgt : REAL;
    dist, stop_d : REAL;
    SCAN_T : REAL := 0.02;
    POSWIN : REAL := 2.0;   (* ← 按轴对象参数覆写 *)
  END_VAR
  (* 梯形轨迹规划体… *)
END_FUNCTION_BLOCK
```

### 2.2 PLC_PRG（按场景生成，核心变化区）

```st
PROGRAM PLC_PRG
  VAR
    (* ── 轴对象实例化 ── *)
    ix_x : INTERP;   (* X 轴插补实例 *)
    ix_z : INTERP;   (* Z 轴插补实例 *)

    (* ── 轴 IO 绑定（%QW 地址来自轴对象定义）── *)
    x_fb   AT %QW0  : INT;   (* X 编码器反馈 ← 驱动器/仿真 *)
    z_fb   AT %QW1  : INT;   (* Z 编码器反馈 *)
    x_cmd  AT %QW10 : INT;   (* X 位置指令 → 驱动器（CSP 插补点流） *)
    z_cmd  AT %QW11 : INT;   (* Z 位置指令 *)

    (* ── 应用指令（主站/测试脚本写入）── *)
    run       AT %QX0.0 : BOOL;
    cmd_home  AT %QX0.1 : BOOL;
    cmd_move  AT %QX0.2 : BOOL;
    quickstop AT %QX0.3 : BOOL;
    x_target  AT %QW12 : INT;
    z_target  AT %QW13 : INT;

    (* ── 应用状态输出 ── *)
    move_done AT %QX1.0 : BOOL;
    any_moving AT %QX1.1 : BOOL;
    prog_id   AT %QW20 : INT := 1;
  END_VAR

  (* ── 轴接线：INTERP 输出 → 位置指令寄存器 ── *)
  ix_x(fire := x_fire, pos_target := x_target, hold_req := quickstop);
  x_cmd := ix_x.Setpoint;    (* CSP: 每扫描发一个插补点 *)

  ix_z(fire := z_fire, pos_target := z_target, hold_req := quickstop);
  z_cmd := ix_z.Setpoint;

  (* ── 应用逻辑（按场景定制的工序/安全/联锁）── *)
  ...
END_PROGRAM
```

### 2.3 PLCopen Motion Control 对齐层（MC_* 标准库，2026-09-09 v4.0）

MC 块命名与语义对齐 PLCopen MC Part 1 单轴子集，作为应用层的固定 API（**生成器只调不改实现**）。完整签名与状态输出组：

| MC 块 | 输入（要点） | 输出 |
|---|---|---|
| `MC_Power` | Enable, EnablePositive/Negative（CiA402 不分方向，仅门控） | Status, Busy, Error |
| `MC_Reset` | fire | Done, Busy, Error |
| `MC_Stop` | fire（电平）, v_act | Done, Busy, Error |
| `MC_Halt` | fire, ax_busy | Stopping, Done, Busy, Error（受控减速停不失能） |
| `MC_MoveAbsolute` | fire, Position, Velocity/Acceleration/Deceleration, sw, abort_bus | Done, Busy, Active, CommandAborted, Error, ErrorID |
| `MC_MoveRelative` | fire, Distance, ActualPosition, 动力学, sw, abort_bus | 同上（绝对目标 = 触发时实际位置 + Distance） |
| `MC_MoveJog` | JogForward/Backward, Velocity, cur_pos, sw | Busy, Error（起跳锚定实际位置） |
| `MC_Home` | fire, sw | Done, Busy, Error |
| `MC_ReadStatus` | Enable, sw, interp_busy, v_act | Valid, Moving, StandStill, Disabled, ErrorStop |
| `MC_ReadActualPosition` | Enable, ActualPosition | Valid, Position |

**ErrorID 枚举**（经 io_list `{axis}_err_id` 诊断出口可读）：0=无 ｜ 1=目标越程 ｜ 2=轴故障 ｜ 3=轴未使能。

**对齐映射与偏差**（生成器须知）：
1. `fire` = 标准的 `Execute`（matiec 保留字，见 §3.3）；`pos_target` = `Position`（INTERP 侧）；
2. **无 AXIS_REF**：轴绑定采用每轴一组 MC 实例（接线即绑定），标准轴引用抽象待真机移植时评估；
3. BufferMode（运动序列缓冲）首版不做；MC_Halt 中止当前命令记 CommandAborted，重发命令即恢复；
4. 动力学参数为 REAL、仅程序内部传递（io_list 仍 {BOOL,INT,WORD} 定点，契约②不变）；MC 块在触发沿把动力学锁存到 `{axis}_vel/acc/dec_bus` 总线供 INTERP 消费；
5. 中止信号（`INTERP.Aborted`）在 MC 块内做**上升沿检测**——上一命令的锁存中止不得误杀新命令（2026-09-09 实测坑）。

**接线约定**（PLC_PRG 生成模板）：目标总线 `{axis}_tgt` 每扫描默认取 `{axis}_sp`，MC_MoveRelative 触发时改写；状态聚合经 MC_ReadStatus（`any_moving`/`fault_any` 路由其 Moving/ErrorStop）。

## 3. 生成规则

### 3.1 变量命名规则

| 类别 | 格式 | 示例 |
|---|---|---|
| 插补实例 | `ix_{axis_name}` | `ix_x`, `ix_z` |
| 位置指令 | `{axis}_cmd AT %QW{n}` | `x_cmd AT %QW10` |
| 编码器反馈 | `{axis}_fb AT %QW{n}` | `x_fb AT %QW0` |
| 目标寄存器 | `{axis}_target AT %QW{n}` | `x_target AT %QW12` |
| 运动触发 | `{axis}_fire` (内部 BOOL) | `x_fire` |
| 状态输出 | `move_done`, `any_moving` | 固定名 |

### 3.2 IO 地址分配规则

```
%QW0~9:    编码器反馈（输入，仿真/驱动器写入）+ 相对距离 rel_{axis}_d（%QW3~5）
%QW10~19:  位置指令（输出，PLC → 驱动器 CSP 设定点流）+ ErrorID 诊断 {axis}_err_id（%QW16~18）
%QW12+n:   目标寄存器（输入，主站写入最终目标）
%QW20:     prog_id（固定）
%QX0.x:    应用指令（主站写入）
%QX1.x:    应用状态输出
%QX2.x:    MC 扩展指令（cmd_halt 2.0 / cmd_rel 2.1，2026-09-09）
```

### 3.3 matiec 限制遵守清单

| 限制 | 对策 |
|---|---|
| `Execute`/`Target`/`Hold`/`DT`/`STEP` 是保留字 | 用 `fire`/`pos_target`/`hold_req`/`SCAN_T`/`pstep` |
| **标识符大小写不敏感**：`busy` 与 `Busy` 同名冲突（2026-09-09 实测） | 同一 POU 内输入输出避免仅大小写差异；必要时 `ax_busy`/`busy_rs` 后缀 |
| INT 不能 AND/OR 位运算 | 控制字/状态字用 WORD |
| FB 内禁 CONSTANT 块 | 参数用带初值的普通 VAR |
| BOOL→INT 需显式转换 | BOOL_TO_INT() |
| 不同 FB 的边沿检测变量必须不同名 | `edge_ir`, `edge_rs`, `edge_ma`, `edge_rl`, `edge_hl`, `edge_jg`, `edge_ab` 等（按 FB 名后缀） |

## 4. 应用逻辑模板

### 4.1 基本运动（goto 模式）

```st
(* 外部写 target 寄存器 → 发 cmd_move 脉冲 → 轴运动到目标 *)
IF cmd_move AND NOT quickstop THEN
    x_fire := TRUE;
    z_fire := TRUE;
END_IF;
IF ix_x.Done AND ix_z.Done THEN
    x_fire := FALSE;
    z_fire := FALSE;
END_IF;
```

### 4.2 带安全互锁的运动

```st
(* Z 轴不在安全高度时禁止 X/Y 运动（龙门/机械手典型联锁） *)
z_safe := (z_fb <= z_safe_limit);
IF NOT z_safe THEN
    x_fire := FALSE;   (* 封锁 X 运动 *)
END_IF;
```

### 4.3 回零

```st
IF cmd_home THEN
    x_target := 0;
    z_target := 0;
    x_fire := TRUE;
    z_fire := TRUE;
END_IF;
```
